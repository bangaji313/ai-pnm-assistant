# Panduan presentasi untuk Dzaky

Durasi contoh 5–7 menit. Gunakan browser desktop dan jaringan stabil; siapkan contoh pertanyaan sebelum memulai. Seluruh data harus sintetis.

1. **Landing:** jelaskan tujuan AI.PNM sebagai teman mencari informasi, lalu pilih Mari Coba.
2. **Akses cepat:** pilih Use Demo Account. Tidak perlu membagikan password atau membuat akun untuk audiens.
3. **Informasi perusahaan:** tanyakan “Apa itu PNM Mekaar?”; tunjukkan jawaban dan Periksa sumber untuk membuka situs resmi.
4. **Konteks aplikasi:** mulai percakapan baru lalu pilih contoh Long Lat UK. Tunjukkan label contoh presentasi/belum disahkan, bukan SOP operasional.
5. **Batas yang bisa dilihat:** coba pertanyaan di luar topik, atau minta cek status dana. Jelaskan bahwa demo tidak punya akses sistem transaksi dan tidak mengarang status.
6. **Saat sumber kurang:** tanyakan topik PNM yang belum tersedia; buka Bantuan lanjutan dan salin draf. Tegaskan belum ada tiket yang dikirim.
7. **Akhiri:** tunjukkan feedback sesi, riwayat tab, lalu keluar. Riwayat bukan milik semua pengunjung demo.

Jika API mendapat rate limit atau koneksi terputus, jelaskan status sebenarnya dan gunakan retry manual. Jangan menyebut teks cuplikan landing sebagai inferensi live. Tidak ada mode tersembunyi yang berpura-pura berhasil ketika provider gagal.

Demo adalah bukti pengalaman dan integrasi teknis. Adopsi operasional memerlukan persetujuan konten PNM, otorisasi pengguna internal, sumber yang aktif, tata kelola data, pengukuran mutu, dan kesiapan dukungan.
